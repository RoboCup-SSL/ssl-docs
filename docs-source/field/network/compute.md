## Physical Network (L1/L2)

### Switching and Cabling

Internet is not guaranteed to be present on the field network.

### DHCP

The network equipment must provide computers with IP addresses via
[DHCP](https://en.wikipedia.org/wiki/Dynamic_Host_Configuration_Protocol). **Teams at the field should expect to be able
to walk up to an unused cable and receive an IP address.** Teams should expect the addresses of field computers and
their own computer to change overnight or between matches, as DHCP leases may expire.

### Power over Ethernet

Some devices, like the remote controls or some camera configurations, require
[Power over Ethernet (PoE)](https://en.wikipedia.org/wiki/Power_over_Ethernet). The network equipment must supply PoE to
the devices that need it. **Teams should not expect to receive PoE unless this has been pre-arranged with the event
organizer.** Event organizers may need substantial heads up to accommodate this request.
