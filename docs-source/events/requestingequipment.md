# Requesting League Equipment

The league owns a set of [Pelicans/travel cases](travelcases.md) containing cameras, lenses, truss computers, cabling,
and mounting hardware for field vision systems and streaming. Event hosts can request these cases to help run their
event. If you would like to use league equipment, please contact the
[executive committee (rc-ssl-ec@lists.robocup.org)](mailto:rc-ssl-ec@lists.robocup.org) and the
[organizing committee (rc-ssl-oc@lists.robocup.org)](mailto:rc-ssl-oc@lists.robocup.org) with your request as early as
possible. Shipping and coordinating transport between events takes time, and the cases may already be committed to
another event. You can also reach us on the [SSL Discord Server](https://discord.com/invite/t724m8c).
