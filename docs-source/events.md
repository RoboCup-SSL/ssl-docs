[SSL website](https://ssl.robocup.org) or [SSL Discord Server](https://discord.com/invite/t724m8c). This documentation
covers how to run an event, not how to attend.

## Hosting a New Event

Hosting a new event can be challenging, but is made substantially easier with the support of the
[league committees](https://ssl.robocup.org/robocups/robocup-2026/robocup-2026-committees/), and a local university. If
you haven't already, please contact the
[organizing committee (rc-ssl-oc@lists.robocup.org)](mailto:rc-ssl-oc@lists.robocup.org) so we can help you.

The committee recommends starting no later than 6-months out from the desired event date for regional events and no
later than 12-months out for large international events. This timeline is mostly due to venue availability being limited
on short notice.

This page provides summary level resources to facilitate choosing a venue and supporting personnel. This wiki has
extensive technical documentation on [field](field.md) and [network](protocol.md) subsystems.

## Early Stages

A good first step would be to identify a head organizer and a technical lead. These individuals would then build a
"local organizing committee" and a "local technical committee".
